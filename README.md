# 포켓몬 데스크탑 컴패니언 (Pokémon Desktop Companion)

화면 위에 항상 떠 있는 작은 창 안에서 포켓몬이 혼자 여행하고, 싸우고, 아이템을 모으며 자라는
데스크탑 다마고치입니다. 다른 일을 하는 동안 포켓몬은 알아서 길을 걷고, 플레이어는 언제든
돌아와서 성장을 확인하고, 기술과 아이템을 정비하고, 잡은 포켓몬을 바꿔 가며 체육관 관장과
포켓몬 리그에 도전합니다.

> **비상업 팬 프로젝트입니다.** Pokémon 및 관련 명칭·이미지·음악의 모든 권리는 Nintendo /
> Creatures Inc. / GAME FREAK inc. 에 있습니다.

## 받기

[Releases](../../releases/latest) 에서 OS에 맞는 파일을 받으세요. 에셋이 패키지에 들어 있어서
추가로 내려받을 것은 없습니다.

| OS | 파일 |
| --- | --- |
| Windows | `*-win-x64.zip` — 압축을 풀고 `Pokemon Desktop Companion.exe` 실행 |
| macOS | 애플 실리콘(M1 이후) `*-mac-arm64.dmg` · 인텔 `*-mac-x64.dmg` |
| Linux | `*-linux-x86_64.AppImage` |

서명 인증서가 없는 개인 프로젝트라 처음 실행할 때 OS가 한 번 막습니다.

- **Windows** — "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
- **macOS** — 앱을 **우클릭 → 열기 → 열기**. 그래도 막히면 터미널에서
  `xattr -dr com.apple.quarantine "/Applications/Pokemon Desktop Companion.app"`
- **Linux** — `chmod +x *.AppImage` 후 실행

세이브와 설정은 앱 바깥에 저장되므로 새 버전으로 바꿔도 그대로 남습니다.

## 시작하기

- **새 게임**에서 세이브 슬롯(3개)을 고르고, 이상해씨·파이리·꼬부기 중 한 마리를 레벨 5로 받아 출발합니다.
- 진행은 **5분마다 자동 저장**됩니다. 설정의 **저장 후 메인 화면으로** / **저장 후 종료**로 직접 저장하고 나갈 수도 있습니다.
- 다시 켜면 **계속하기**에서 이어 합니다.

## 창과 조작

- 창은 화면의 약 1/16 크기로 **항상 다른 창 위에** 떠 있습니다. 크기는 설정의 **화면 크기**에서 바꿉니다.
- 창 위쪽이나 게임 그림 바깥을 끌면 창이 움직이고, 위치와 크기는 기억됩니다.
- **화면을 누르고 있으면 빨리 감깁니다.** 걷는 속도가 2.5배, 다음 이벤트까지의 대기와 진행 중인
  이벤트(나무열매 따기, 아이템 줍기 등)가 6배로 빨라지고, 손을 떼면 원래 속도로 돌아옵니다.
- 전투 중에는 화면을 누르면 메시지가 빨리 넘어갑니다.
- **가방·도감·설정·상점을 열어도 포켓몬은 계속 걷습니다.** 메뉴가 열려 있는 동안에는 새 이벤트만 잠시 미뤄집니다.

## 여행

포켓몬은 실제 GBA 맵 위를 걷습니다 — **에메랄드의 호연 28곳**과 **파이어레드의 관동 29곳**입니다.
시간대(새벽·낮·오후·저녁·밤)에 따라 맵의 빛이 바뀌고, 비가 오는 119번도로나 모래바람이 부는 111번도로처럼
그곳의 날씨가 길 위와 전투에 그대로 내립니다.

**1분마다 이벤트가 하나 일어납니다.**

| 이벤트 | 내용 |
| --- | --- |
| 나무열매 | 길가의 나무에서 나무열매를 땁니다 |
| 아이템볼 | 길에 떨어진 아이템을 줍습니다 |
| 야생 포켓몬 | 야생 포켓몬과 싸웁니다. 이기면 포획 기회가 생깁니다 |
| 트레이너 | 트레이너와 싸웁니다. 가끔 체육관 관장이 나옵니다 |

- 방금 나온 이벤트는 다음 차례에 잘 나오지 않아서 같은 일이 연달아 반복되지 않습니다.
- **이벤트가 10번 일어나면 다른 장소로** 이동합니다. 대개 같은 지방 안에서 움직이고, 20% 확률로 다른 지방으로 건너갑니다.

### 포켓몬센터

포켓몬센터는 무작위로 나오지 않고 **필요할 때 찾아옵니다.** 아래 중 하나가 새로 생기면 다음 이벤트가
포켓몬센터가 됩니다.

- 체력이 최대의 1/4 이하
- 기술 PP가 거의 바닥남
- 가방에 회복약이 없음
- 가방에 볼이 없음

센터에 들어가면 체력·PP가 모두 회복되고, **레벨에 맞는 상처약 8개와 볼 1~2개**를 받습니다.
포켓몬이 전투에서 쓰러져도 다음 이벤트는 바로 포켓몬센터입니다.

## 전투

전투는 **자동으로** 진행됩니다. 무엇을 쓸지는 [자동전투 설정](#자동전투-설정)이 정합니다.

- 동행 포켓몬은 혼자 다니는 대신 **받는 데미지가 절반**이고, **약점 공격은 2배가 아니라 1.5배**로 들어옵니다.
  주는 데미지는 그대로입니다.
- 기술·특성·지닌 물건·날씨·필드·상태이상은 최신 세대 규칙을 따릅니다. 특성은 거의 전부 동작하고,
  1:1 배틀에서 의미가 없는 특성은 설명에 **"1:1 배틀에서는 효과가 없다."** 라고 적혀 있습니다.
- 전투 화면의 **가방** 버튼으로 회복약을 직접 쓸 수 있습니다. 쓰면 그 턴의 행동을 대신합니다.
- 행동 순서는 기술 우선도 → 스피드 순이고, **스피드가 같으면 매 턴 무작위**입니다. 그래서 한쪽이
  턴 끝과 다음 턴 처음에 연달아 움직여 두 번 공격한 것처럼 보일 때가 있습니다.
- 전투에서 소모한 지닌 도구(기합의띠·풍선 등)는 전투가 끝나면 돌아옵니다. 먹은 나무열매만 사라집니다.

**지면** — 야생 포켓몬이면 그 포켓몬의 포획 기회를 잃고, 트레이너라면 상금을 냅니다. 어느 쪽이든
다음 이벤트는 포켓몬센터입니다.

### 자동전투 설정

포켓몬 탭의 **자동전투 설정**에서 정합니다. 위에서부터 순서대로 결정합니다.

1. **모드** — 전체 반복 / 마지막 기술 반복 / 데미지 우선
2. **기술 사용 순서** — 칸에 넣은 기술을 차례로 씁니다. 상대에게 통하지 않는 기술은 건너뜁니다.
3. **기술 종류별 사용 조건** — 순서 칸이 비었거나 쓸 수 있는 기술이 없을 때, 공격·상태이상·랭크 변화·
   필드·회복 기술을 각각 언제 쓸지(미사용 · 항상 · 전투 시작 시 · 상대가 멀쩡할 때 · 상대가
   상태이상일 때 · 필드가 없을 때 · 체력 2/3·1/2·1/3·1/4 이하) 정합니다.

아무것도 정하지 않으면 공격 기술 중 **기대 데미지가 가장 큰 것**을 씁니다.

## 포획

야생 포켓몬은 **쓰러뜨린 다음에** 잡습니다.

- 이기면 그 포켓몬이 화면 오른쪽 위 **포획 대기**에 올라갑니다(최대 5마리). 원할 때 아이콘을 누르면 포획 화면이 열립니다.
- 포획 화면에는 가방의 볼과 **볼마다의 실제 포획 확률**이 표시되고, **기회는 3번**입니다. 3번 모두
  실패하면 포켓몬은 도망칩니다. 취소하면 대기줄에 그대로 남습니다.
- **은 라즈열매·황금 라즈열매**가 있으면 볼 위 줄에서 먼저 줄 수 있습니다. 다음 볼의 포획률이
  1.5배·2.5배가 됩니다.
- 잡은 포켓몬은 **레벨 5로 초기화되어** 박스에 들어갑니다. 바로 쓰는 전력이 아니라 새로 키울 동료입니다.
- 포획 대기는 저장되지 않습니다. 게임을 끄면 사라집니다.

**볼마다 잘 듣는 상황이 다릅니다.** 특수 볼은 조건이 맞으면 원작보다 강하고, 안 맞으면 몬스터볼보다 약합니다.

| 볼 | 잘 듣는 때 |
| --- | --- |
| 슈퍼볼 · 하이퍼볼 | 언제나 (1.5배 · 2배) |
| 퀵볼 | 첫 번째로 던질 때 |
| 타이머볼 | 던진 볼이 많을수록 |
| 다크볼 | 밤(21시~5시)이나 동굴 |
| 네트볼 | 물·벌레 타입 |
| 다이브볼 | 물가·해변 |
| 네스트볼 | 레벨이 낮은 포켓몬 |
| 리피트볼 | 이미 잡은 적 있는 종 |
| 레벨볼 | 동행 레벨이 상대보다 높을수록 |
| 문볼 | 달의돌로 진화하는 종 |
| 스피드볼 | 빠른 포켓몬 |
| 러브러브볼 | 동행과 같은 종, 다른 성별 |
| 헤비볼 | 무거운 포켓몬 |
| 울트라볼 | 울트라비스트 (울트라비스트에게는 다른 볼이 거의 듣지 않음) |
| 마스터볼 | 반드시 잡힘 |

**이로치**는 원작처럼 1/4096 확률로 나오고, 어디서든 이름 옆에 **★**가 붙습니다.

### 야생에서 만나는 포켓몬

- 지역마다 원작의 출현 테이블을 따르고, 그와 별개로 **30%는 전국 도감 전체**에서 나옵니다.
  지역의 지형에 어울리는 타입이 더 자주 나옵니다.
- 전설·환상·패러독스·울트라비스트는 아주 드뭅니다(합쳐서 약 500번에 1번).
- 야생 포켓몬의 레벨은 동행 레벨 근처이고, 그 레벨에 맞는 진화 단계로 나옵니다.
- 야생에서 만난 포켓몬은 **숨겨진 특성**을 가지고 있을 수 있습니다.

## 성장

- **레벨업**하면 새 기술을 배웁니다. 기술 칸이 가득 차 있으면 포켓몬 탭의 기술 칸에 **빨간 점**이
  붙고, 기술을 눌러 교체 목록에서 바꿀 수 있습니다.
- **진화**는 조건이 맞으면 이긴 전투가 끝날 때 자동으로 일어납니다. 진화의 돌처럼 쓰는 도구는
  가방에서 사용하고, 통신교환 진화는 **연결의끈**으로 합니다. 친밀도·걸음 수·시간대·지역·지닌
  도구 등 원작의 진화 조건 대부분이 그대로 있습니다.
- 성격·개체값·특성은 원작과 같고, **노력치는 없습니다.** 능력치는 포켓몬 탭에서 볼 수 있고,
  성격이 올리는 능력치는 빨간색, 내리는 능력치는 파란색입니다.
- 민트(성격 변경), 특성캡슐·특성패치, 병뚜껑(개체값), 포인트업, 경험사탕, 이상한사탕 같은 도구도
  가방에서 쓸 수 있습니다.

## 가방

| 탭 | 내용 |
| --- | --- |
| 포켓몬 | 동행 포켓몬의 능력치·특성·지닌 물건·기술·배지, 자동전투 설정 |
| 아이템 | 회복·도구·나무열매·볼·기술머신 |
| 박스 | 잡은 포켓몬 |

- 회복약·기술머신은 **사용**, 도구와 나무열매는 **지니게 하기**를 합니다. 지닌 물건은 포켓몬 탭에서
  눌러 돌려받습니다.
- 기술머신 탭의 **배울 수 있는 기술머신만**을 켜면 지금 포켓몬이 배울 수 있는 것만 보입니다.
- 지니는 도구와 기술머신처럼 **없어지지 않는 아이템은 하나만** 가질 수 있습니다.

### 사용 설정

아이템 탭의 **사용 설정**에서 가방을 열지 않아도 알아서 굴러가는 것들을 정합니다.

- **나무열매 자동 보충** — 전투에서 열매를 먹어 손이 비면 정해 둔 1~3순위 열매를 들려줍니다.
  **추천** 버튼은 지금 포켓몬에 맞춰 순위를 채우고, **알맞은 나무열매 자동 장착**을 켜 두면 순위의
  열매가 없을 때 가방에서 가장 알맞은 열매를 골라 줍니다.
- **회복 아이템 사용** — 체력이 정한 만큼 떨어지면 그 턴에 회복약을 씁니다.

### 박스

- 박스는 칸 제한이 없습니다. **즐겨찾기**한 포켓몬은 맨 앞에 모입니다.
- **이 포켓몬으로 변경**으로 동행 포켓몬을 바꿉니다.
- 놓아주기도 여기서 합니다.

## 상점과 돈

필드 오른쪽 아래, 지역 이름 왼쪽의 **상점** 버튼으로 언제든 엽니다.

- 새 여행은 **3,000원**으로 시작합니다.
- 트레이너를 이기면 상금을 받습니다(상대의 마지막 포켓몬 레벨 × 트레이너 40원 · 관장 100원 · 리그 200원).
  지면 배지 수에 따라 돈을 냅니다. 야생 포켓몬은 돈과 상관없습니다.
- 회복약·볼·나무열매·지니는 도구·기술머신 등 대부분을 팝니다. 전설 포켓몬의 폼 도구, 플레이트,
  마스터볼처럼 특별한 물건은 팔지 않습니다.
- **진화 아이템(10,000원부터)과 기술머신(20,000~50,000원, 위력이 높을수록 비쌈)은 비쌉니다.**
  한 번 사면 영영 남는 물건이라 길에서 주울 가치를 남겨 두었습니다.

## 체육관과 포켓몬 리그

- **체육관 관장**은 트레이너 이벤트 대신 나옵니다. 이기면 그 관장의 **배지**를 받습니다. 배지가
  늘수록(또는 레벨이 앞서 있을수록) 관장이 자주 나오고, 트레이너를 연달아 이기면 관장이 찾아옵니다.

  | 단계 | 배지 | 또는 레벨 | 관장이 나올 확률 | 관장을 부르는 연승 |
  | --- | --- | --- | --- | --- |
  | 초반 | 0–3 | 30 미만 | 5% | 25 |
  | 중반 | 4–5 | 30–44 | 10% | 15 |
  | 후반 | 6–7 | 45 이상 | 15% | 10 |

- **배지 8개를 모으면** 필드 아래쪽에 **포켓몬 리그로 간다** 버튼이 생깁니다.
- 리그는 **사천왕 4명과 챔피언**을 차례로 상대합니다. 들어설 때마다 석영·호연·신오·하나·칼로스·
  알로라·팔데아·블루베리 리그 중 하나가 뽑히고, 상대는 원작 로스터 그대로입니다. 라운드 사이에는
  체력이 회복됩니다.
- 라운드 사이에 **정비한다**로 나갔다가 다시 들어가면 이긴 곳부터 이어서 합니다. 지면 처음부터입니다.
- 챔피언을 이기면 그 포켓몬은 **챔피언**이 되고, 박스 아이콘에 금색 왕관이 붙습니다.
- **배지와 챔피언 칭호는 포켓몬마다** 따로입니다. 동행을 다른 포켓몬으로 바꾸면 그 포켓몬은 배지 0개에서 시작합니다.
