포켓몬·특성·기술·아이템의 이름·설명·효과를 전수 점검한 결과입니다.
README가 이미 미구현이라고 밝힌 것(특성 34개 목록의 예시, "아직 효과가 없습니다" 표시가 붙는 아이템)은
빼고, **밝히지 않은 미구현과 잘못 동작하는 것**만 모았습니다.

점검 방법: `npm run assets -- --only dex` 로 데이터를 새로 빌드한 뒤(종 1084 · 기술 914 · 특성 311 ·
아이템 782), 저작 패치(`item-texts.json`, `move-texts.json`)를 게임과 같은 방식으로 덮어쓰고
엔진 코드(`app/renderer/engine/*`)와 한 항목씩 대조했습니다. "배울 수 있는 기술"은 어떤 종이든
레벨업·기술머신으로 배울 수 있는 761개입니다.

문제없음으로 확인된 것:

- 기술 914개·아이템 782개·특성 311개·종 1084개 모두 한국어 **이름**이 있음 (저작 패치 포함)

- 엔진이 내보내는 전투 로그 종류는 전투 화면이 전부 문장으로 처리함

### 3차 점검 — 폼 (2026-09-25)

데이터를 새로 빌드해(종 1101 · 폼 90개/37종) 폼 표(`forms.mjs`)·배틀·가방·도트 경로를 대조했습니다.
폼이 참조하는 도구 슬러그·폼 슬러그·기술·특성·한국어 이름·앞면 스프라이트는 전부 존재했고,

걷는 그림이 없는 것은 전투에서만 나오는 4개 폼(윽우지 둘·스텔라폼·가라르 달마모드)뿐입니다.

있습니다. 큐레무·후파는 아는 기술만 바꾸고, 분리한 버드렉스는 기본 모습이 못 배우는 기술도 잊습니다.
참고한 포켓로그는 폼 변경 때 기술을 건드리지 않고(`Pokemon.changeForm`), 폼 전용기는 폼의 배우는
기술 목록에 두어 떠올리기로 얻게 합니다 — 이 게임에는 떠올리기 수단이 없어 따르지 않았습니다.
